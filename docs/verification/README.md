# 検証記録

> English: [README.en.md](./README.en.md)

最終更新：2026-10-11（対象版：v0.12.0、commit `220bf0d`）

## 要点

- **テストスイート**：427 件成功・1 件スキップ。CI（Ubuntu / macOS / Windows）で成功しています。
- **入口ゲート（`zee gate`）**：検査が不完全なとき通さない作り（v0.11.0）、指示すり込み検出の正規化と二段判定（v0.12.0）、入力によって処理時間が急増する問題の修正（v0.12.0）を、再現試験つきで反映しています。測定できた限界も同じ表に載せています。
- **囮・封じ込め**：テストスイートと、隔離した macOS 環境での dry_run の実演（v0.10.1 付近の版で実施。v0.12.0 では再実施していません）で確認しています。
- **まだ行っていないこと**：専門家・第三者機関による独立評価、Linux・Windows 実機での実遮断と連続稼働。実遮断（`dry_run: false`）は GitHub の仮想ランナーと macOS 実機1台で行いました（[real-cut.md](./real-cut.md)）。下の「未実施の範囲」を参照してください。

## 試験ではないもの

- 公開されている自律型の攻撃ツールを、実行せずに公開資料だけで読んで Zee の設計と突き合わせた机上の分析（2026-10-10）を行いました。結果は、読み取り中心の攻撃には自動遮断が働かず通知のみ、という既存の設計（README の Limitations）の確認です。実機での試験ではありません。

## 計測の仕組みと未公表の数値

Zee は検知レイテンシ・遮断完了時刻・誤検知マーカーを `metrics.jsonl` に記録する作りになっています。これらを集計した結果は、まだ公表していません。

## 未実施の範囲

- **専門家・第三者機関による独立評価**：受けていません。
- **実遮断（`dry_run: false`）の範囲**：GitHub の仮想ランナー（Linux はネットワーク名前空間、macOS、Windows は英語版）と macOS 実機1台で行いました（[real-cut.md](./real-cut.md)）。Linux・Windows の実機、英語以外の Windows、IPv6、遮断前から開いていた接続、macOS 実機での v0.13.0 の規則は試していません。テストスイートは OS の遮断コマンドを差し替えて分岐を検証しています。
- **Linux・Windows 実機での連続稼働**：CI のテストとスモークテストは通っていますが、実機で長時間動かした検証はありません。
- **実際の AI エージェントが指示に従うか**：V3・V4 は検査器が検出するかどうかの静的な試験で、エージェントの挙動は試していません。
- **入口ゲートの動的検査・Rug Pull・条件分岐の実行時挙動**：評価していません。
- **通常運用での誤検知率**：測定していません（V4 は良性 10 件のみ）。
