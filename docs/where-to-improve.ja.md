最終更新 2026-11-01 ／ English: not published yet

## Zee の役割

**侵入が成立した後に、被害が拡大することを抑止する**ための実装です。Zee が担当するのは侵入防止の次の層であり、**囮（decoy）への接触を検知し、当該端末の外向き通信を遮断する**ところまでを自動で行います。

設計の原則は3点です。

1. 侵入は発生するものとして設計する。
2. 攻撃者の道具の無害化を目的としない。駆除・解析・反撃は行わず、**被害が外部へ流出する経路の遮断**に限定する。
3. 防御は公開によって強度が上がる。実装は全て可読であり、検証と指摘によって改善する。

## 現在の検証範囲（実機とそれ以外を区別）

| 機能 | 状態 |
|---|---|
| 囮への接触の検知（変更系＝書き換え・削除・改名） | 動作する |
| 外向き通信の自動遮断 | 動作する。**既定は `dry_run`（観測のみ）**。`response_mode: auto` かつ `dry_run: false` を明示した場合に限り実遮断を行う |
| macOS の遮断 | 実機1台で検証済み |
| Linux の遮断（nft・iptables） | 名前空間内で IPv4・IPv6 の遮断と復旧を実測。**物理機での検証は未了** |
| Windows の遮断 | **IPv4 は実遮断と復旧を確認**（英語版の仮想ランナー）。**IPv6 は規則の投入と再読み込み時の一致まで**で、実遮断は未検証（検証環境に IPv6 の外向き経路がないため）。**日本語版 Windows 実機での検証は未了** |
| 読み取りのみの接触 | 自動遮断の対象外（正規のソフトウェアの読み取りが多く、遮断の業務影響が大きいため）。**macOS・Windows では通常の読み取りを観測できません**（OS の通知機構が読み取りを出さないため）。`ZEE_CANARY_BASE_URL` を設定した場合に限り、囮に埋め込んだ URL が辿られた時点で利用者が指定した外部エンドポイントで発火します（Zee 本体には戻りません）。検知できた場合の扱いは通知と手動遮断の案内に留める |
| 外向き遮断が及ばない範囲 | **既に確立している通信**（macOS・Windows では新規の接続だけが対象。検証も新規接続で測定）、**私用アドレス宛ての通信**（VPN・オーバーレイ等）など。経路ごとの差を含め、詳細は [改変と共同開発者の記載について](./co-developers.ja.md) の第2節と `docs/verification/real-cut.md` |
| 誤検知率 | **未測定。** 未測定の事実を「低い」と言い換えない |

## ここに手を入れると効きます

当方の環境では充足できない箇所、すなわち**台数・環境・別の視点**が不足している箇所を挙げます。

1. **日本語版 Windows 実機での検証。** 当方は x64 の Windows 実機を保有せず、検証は仮想環境と英語版に限られます。`docs/verification/real-cut.md` の手順に従って実行し結果を記録するだけでも、上表の1行が確定します。IPv6 の外向き経路を持つ環境であれば、さらに情報量が増えます。
2. **誤検知の実例。** 正規のソフトウェアによる発報の報告は、**欠陥の報告と同等**に扱います。単一環境では取得できない種類の情報です。
3. **攻撃側からの検証。** 隔離環境で Zee を突破し、その経路を記録した結果。防御側が想定する攻撃は、設計の内側に収まる傾向があります。
4. **読み取りの検知**（macOS の Endpoint Security、Windows の Object Access 監査）。現時点で未到達の層です。資格の申請と環境面の制約により、当方では進捗が停止しています。

1 と 2 はコードの記述を伴わなくても成立します。

なお、当方では次を並行して進めています（重複を避けるための現在地です）：Linux 遮断の実測、誤検知の測定、OS 別の遮断実装の改善、文書の整備と英語版。

## 禁止事項

次に該当する機能は、**本プロジェクトでは取り込まず、共同開発者としての記載も行いません。** これは本プロジェクトが受け入れる範囲の表明であり、**MIT ライセンスの許諾条件を変更するものではありません**（詳細は [改変と共同開発者の記載について](./co-developers.ja.md) の第5節）。

- **ハックバック（反撃）に相当する機能**：攻撃元とみなした相手への侵入・接続の試行、妨害、停止、データの削除・改ざん。
- **第三者の機器・システム・データへの無断のアクセス・取得・改変・破壊。** 攻撃者のものと推定される対象も同様です（帰属の推定は誤りうるため）。
- **通信の傍受、なりすまし、認証情報の窃取。**
- **適用される法令に違反する機能。**
- **第三者のサービスの利用規約に違反する操作**を前提とする機能。

隔離した自己管理下の環境での Zee 自身への攻撃検証は対象外です。
